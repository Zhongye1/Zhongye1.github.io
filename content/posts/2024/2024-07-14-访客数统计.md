- 不蒜子官网：www.busuanzi.cc
- 仅需在网页中引入一行脚本和一行标签代码即可完成部署。
- 访问量(PV)：记录页面访问量，单个用户每访问一次就会计数 1 次。
- 访客数(UV)：记录独立访客数，单个用户在同一天内多次访问只会被计数 1 次。

## 使用

使用不蒜子统计必须在页面中引入脚本 busuanzi.min.js (支持本地部署) 两个脚本只能二选一。

1、访问数据显示全部完整数字 ( 例如: 1234 次 )

```html
<script src="//cdn.busuanzi.cc/busuanzi/3.6.9/busuanzi.min.js" defer></script>
```

2、访问数据显示数字格式化 ( 例如: 1.23K 次 )

```html
<script src="//cdn.busuanzi.cc/busuanzi/3.6.9/busuanzi.abbr.min.js" defer></script>
```

数字格式化：1000=1K，10000=1W，100000000=1E。

四舍五入算法：1014=1.01K，1015=1.02K。10140=1.01W，10150=1.02W。

## 统计代码

```html
<script src="//cdn.busuanzi.cc/busuanzi/3.6.9/busuanzi.min.js" defer></script>
今日总访问量 <span id="busuanzi_today_pv">加载中...</span> 次 今日总访客数
<span id="busuanzi_today_uv">加载中...</span> 人 本站总访问量
<span id="busuanzi_site_pv">加载中...</span> 次 本站总访客数
<span id="busuanzi_site_uv">加载中...</span> 人 本页总阅读量
<span id="busuanzi_page_pv">加载中...</span> 次 本页总访客数
<span id="busuanzi_page_uv">加载中...</span> 人
```
