# INTRO

一些场景下，个人比较喜欢纯键盘操作和TUI，平时会折腾下 Neovim

nvim最头疼的往往是插件管理与配置，容易踩坑，看到有项目 one.nvim 在试着把这些问题打包解决，在这里做分享

主要特点

- 完全使用 Lua 编写，所有配置均可覆盖。
- 充分利用 Neovim 的现代特性：原生 LSP、浮动窗口 (Float Window)、顶栏 (Winbar)。
- 支持的插件管理器：lazy.nvim。
- 精致的 UI 与配色方案。深色模式，支持真彩色 (True-Color)、平滑滚动 (Smooth-Scroll)、滚动条 (Scrollbar)、仪表盘 (Dashboard)。颜色与高亮可自由修改，详见 Colors and Highlights。
- 集成 130+ 个强大的 Vim/Nvim 插件，优化使用体验，并修复了部分插件的不足之处。

![](https://pic2.zhimg.com/v2-83f5017e8dab9226d6bda9dbecc3c58f_r.jpg)

# 安装

Neovim 版本 0.12.2 , 动效强推 Neovide

nvim配置

```bash
PLUGIN_DIR=$HOME/.local/share/nvim/plugins/one.nvim
mkdir -p "$PLUGIN_DIR"
git clone --single-branch https://github.com/adoyle-h/one.nvim.git "$PLUGIN_DIR"/one.nvim
```

完成 clone 后，首次启动 nvim 会自动进入插件安装界面(没有lazyvim就按照提示安装)

如下图所示，可以看到任务栏的 Install / Update / Sync / Clean / Check / Log / Restore / Profile / Debug / Help 等操作入口，下方实时显示每个插件的克隆进度。

![alt text](https://pic3.zhimg.com/v2-7233a62dc4f9fd873c980aadb1cbfefa_r.jpg)

首次启动会有 80+ 插件并行下载，网络不佳时会卡在 Working 列表。建议挂代理或使用 ghproxy 镜像。
